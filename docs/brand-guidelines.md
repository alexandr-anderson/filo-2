## 2. Typography

### Font Stack

```css
--font-heading: 'Prata', Georgia, serif;
--font-body: 'Manrope', system-ui, sans-serif;
```

Prata выбрана вместо DM Serif Display с сайта бренда: у DM Serif Display нет кириллицы. Оба шрифта контрастные дидоны, характер сохраняется.

## 3. Voice

- **Экспертный:** говорим как технолог, который сам работает с продуктом. Называем процедуру и результат, а не «волшебство».
- **Тёплый:** обращаемся на «вы», без канцелярита. Мастер и его клиентка для нас люди, а не «целевая аудитория».
- **Конкретный:** цифры, составы, объёмы, сроки доставки. Без слов «уникальный», «инновационный», «премиальный» без доказательства.

| Пишем | Не пишем |
|-------|----------|
| Гладкость до 3 месяцев после процедуры [проверить у клиента] | Невероятный эффект |
| Оптовые цены видны сразу, без запроса | Выгодные условия для партнёров |
| Ответим в Telegram в рабочее время | Мы всегда на связи |

Типографика текста: без длинных тире как украшения, кавычки «ёлочки», буква «ё» обязательна.

## 4. Logo

- Название в логотипе и заголовках: **Filó** (с ударением, как у бренда). В тексте и URL допускается Filo.
- Логотип бренда используется только в предоставленном клиентом виде. Прототипы используют текстовый знак FILÓ до получения файла логотипа.
